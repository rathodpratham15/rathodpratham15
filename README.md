## 🚀 Selected Projects

### Orqen
🔗 https://orqen.pratham.click

Custom AI agent execution platform built from scratch.

- BFS DAG execution engine for deterministic workflow orchestration
- 7 typed node primitives including LLM tool use, sandboxed code execution,
  human approval gates, and control flow operations
- Celery + Redis distributed worker architecture
- Execution tracing, observability, and fault-tolerant retries
- Multi-provider LLM support with structured outputs
- Built without LangGraph or other workflow frameworks

**Tech:** Python · FastAPI · Celery · Redis · PostgreSQL · React · TypeScript
